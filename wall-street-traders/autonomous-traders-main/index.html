SECURITY
Threat model (harden v7)
MAIN ONLY

          

            
No private keys on site. Pilot key-paste UI removed. Arcus is BYOS: Edge issues unsigned intents; external signer returns headers+body; Edge rechecks ownerOf+caps and proxies to Arcus testnet. RH Chain stores session_pub + policy meta only.

            
Trust boundaries. Wallet ownership via one-time personal_sign challenges for activate/arm/disarm/revoke. Every place path re-checks NFT ownerOf and auto-revokes/disarms on transfer. Actor labeled holder vs agent.

            
Caps. Hard max_notional_usd with drip spent tracking. Hard max_loss_usd via Arcus mainnet mids mark check. Env forced to Arcus TESTNET unless caps.allow_mainnet===true. Short GTT (15–60 min).

            
CORS. Default allowlist (commitprotocol.org + localhost). Override via Edge secret CORS_ORIGIN_ALLOWLIST. Never reflects *.
